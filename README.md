
# 🏰 Magic Academy 

Una plataforma web inspirada en el concepto de una academia mágica, desarrollada originalmente durante un bootcamp y posteriormente refactorizada para eliminar dependencias externas y contenido con copyright.

El proyecto funciona como una demostración de desarrollo web utilizando HTML, CSS y JavaScript, con una organización modular de archivos y datos locales en formato JSON.

---


## ✨ Características

- 📚 Biblioteca de libros de magia.
- ✨ Grimorio de hechizos.
- 👨‍🏫 Directorio de profesores.
- 🦁 Sistema de tres casas.
- 📝 Encuesta de clasificación.
- 🔐 Sistema de registro y acceso.
- 💾 Datos almacenados mediante archivos JSON locales.

---

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- JSON
- Python (Backend académico)


---

## 🔄 Refactorización

Esta versión del proyecto incluye una limpieza importante respecto a la versión desarrollada durante el bootcamp.

Se realizaron los siguientes cambios:

- Eliminación de referencias directas a franquicias con copyright.
- Reemplazo de APIs de terceros por archivos JSON locales personalizados.
- Creación de contenido propio (casas, profesores, libros y hechizos).
- Reorganización de la estructura del proyecto separando Frontend y Backend.
- Simplificación del código JavaScript para consumir datos locales.
- Sustitución de imágenes y recursos externos por recursos propios.

---
